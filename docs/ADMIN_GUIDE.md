# دليل المشرف

أوامر المشرف تُرسل **في محادثة خاصة مع البوت** (لا تعمل في المجموعات)، من رقم مشرف فقط:
- أرقام في `ADMIN_IDS` (متغير بيئة، تُزال بتعديله فقط)، أو
- أرقام أضفتها بالأمر `/admin add`.

غير المشرف الذي يكتب `/…` يُعامَل كأنه يبحث نصًا عاديًا. اكتب `/help` لقائمة مختصرة.

## الحالة والأعداد
| الأمر | الوظيفة |
|---|---|
| `/status` | صحة النظام: آخر مزامنة لتيليجرام ودرايف، المزامنات الجارية الآن (منذ كم دقيقة وما يقرؤه)، تحذير «stale» إن تأخرت المزامنة، مصادر درايف وأخطاؤها |
| `/stats` | أعداد: رسائل تيليجرام، ملفات درايف، الموارد حسب حالة التصنيف، العُقد، الجلسات الجارية، ونتائج الإرسال آخر 7 أيام |

## المزامنة
| الأمر | الوظيفة |
|---|---|
| `/sync` أو `/sync all` | مزامنة تيليجرام ودرايف الآن |
| `/sync telegram` / `/sync drive` | واحد منهما |

- **تعمل في الخلفية:** يردّ البوت فورًا «بدأت المزامنة» ويبقى كل شيء آخر متاحًا، ثم تصلك رسالة بالنتيجة والمدة. تابع التقدم بـ `/status`.
- إن كانت المزامنة جارية يخبرك بذلك ولا يبدأ أخرى.
- المزامنة التلقائية تتكرر وفق `sync.telegram.intervalMinutes` و`sync.drive.intervalMinutes`، وتعيد قراءة كل رسائل الفهارس في كل مرة فتظهر تعديلاتها دون تدخل.

## الإعدادات (بلا إعادة نشر)
| الأمر | الوظيفة |
|---|---|
| `/settings` | قائمة كل الإعدادات وقيمها (النجمة `*` = معدّل، `↻` = يحتاج إعادة تشغيل) |
| `/set <مفتاح> <قيمة>` | تغيير إعداد |
| `/reset <مفتاح>` | الرجوع للافتراضي |

الأمثلة:
```
/set search.pageSize 10
/set links.drive false
/set delivery.allowedMediaTypes pdf mp3 docs
/set delivery.maxAttachmentMb 500
/set group.triggers ! مكتبة
/reset delivery.allowedMediaTypes
```
القوائم تفصل بمسافة أو فاصلة. المرجع الكامل بكل المفاتيح وافتراضياتها: [`SETTINGS.md`](SETTINGS.md).

### أهم الإعدادات
| المفتاح | ما يفعله |
|---|---|
| `links.telegram` / `links.drive` | إظهار/إخفاء كل نوع روابط بشكل مستقل (كلاهما يعمل معًا أو منفردًا) |
| `delivery.sendAttachment` | `false` = روابط فقط بلا إرسال ملفات |
| `delivery.maxAttachmentMb` | أكبر ملف يُرسل فعليًا (ما فوقه روابط). واتساب يقبل حتى 2000MB لكن الاستضافة المجانية لا تتحمل |
| `delivery.allowedMediaTypes` | أنواع الملفات المسموح إرسالها: كلمات (`pdf`، `audio`، `video`، `image`، `document`، `docs`/`word`، `excel`، `ppt`)، أو امتدادات (`.mp3`)، أو MIME (`application/pdf`، `audio/*`). فارغ = كلها |
| `delivery.concurrency` | عدد عمليات الإرسال المتوازية (يحتاج إعادة تشغيل). 1 للاستضافة الصغيرة |
| `delivery.timeoutSeconds` | مهلة «بلا تقدم» في التنزيل (تُجدَّد كلما وصلت بايتات) |
| `delivery.progress` / `delivery.progressMinMb` | إظهار رسالة التقدم، والحد الأدنى لحجم الملف المفرد لإظهارها |
| `delivery.splitLargeAudio` | تقسيم الصوت فوق 16MB إلى أجزاء (`false` = روابط فقط) |
| `delivery.audioPartMb` | حجم الجزء عند التقسيم (2 إلى 15) |
| `delivery.audioMode` | `audio` رسالة صوتية (الافتراضي) أو `document` مرفقًا |
| `delivery.driveDownload` | السماح بتنزيل ملفات درايف وإرسالها (متوقف افتراضيًا) |
| `delivery.maxBatch` | أقصى عدد ملفات في الطلب الواحد |
| `group.mode` / `group.replyMode` / `group.triggers` | سلوك المجموعات والبادئات |
| `library.rootIndexMessageId` | فهرس الرئيسية يدويًا (الافتراضي: يُكتشف تلقائيًا) |
| `library.indexAliases` | ترجمة أسماء المواد العربية إلى عناوين الفهارس (للانتقال السريع) |
| `keepalive.intervalMinutes` | إبقاء الخدمة والقاعدة مستيقظتين (0 = تعطيل) |
| `whatsapp.minSendGapMs` | أقل فاصل بين إرسالين (يخفف خطر الحظر) |
| `rateLimit.perParticipantPerMinute` | حد الرسائل لكل شخص في الدقيقة |
| `text.welcome`, `cohort.label`, `bot.language` | نصوص ولغة البوت |

## مصادر Google Drive
| الأمر | الوظيفة |
|---|---|
| `/sources` | قائمة المصادر |
| `/source add <اسم_بلا_مسافات> <رابط-المجلد> [credential_ref]` | إضافة مجلد (الشرطة السفلية تصير مسافة في الاسم) |
| `/source on <id>` / `/source off <id>` | تفعيل/إيقاف مصدر |

أضف المجلد ثم شاركه مع بريد حساب الخدمة (Viewer) ثم `/sync drive`. التفاصيل: [`DRIVE_SETUP.md`](DRIVE_SETUP.md).

## مراجعة التصنيف
الفهرسة اليومية تعتمد على فهارس القناة نفسها ولا تحتاج تصنيفًا؛ هذه الأوامر لبحث الملفات وتنظيمها:
| الأمر | الوظيفة |
|---|---|
| `/review [صفحة]` | الملفات غير المصنفة أو المحتاجة لمراجعة (مع اقتراح المكان) |
| `/nodes [id]` | عرض شجرة الفصول والمواد (بلا id: المستوى الأعلى) |
| `/assign <resourceId> <nodeId>` | وضع ملف في مكان معيّن **وقفله** فلا تنقله المزامنة |
| `/unlock <resourceId>` | فك القفل ليُعاد تصنيفه تلقائيًا |
| `/alias add <nodeId\|rID> <نص>` | مرادف بحث لعقدة أو ملف (مثال: `/alias add 12 تشريح`) |
| `/alias list` / `/alias del <id>` | عرض/حذف المرادفات |

## المشرفون والتدقيق
| الأمر | الوظيفة |
|---|---|
| `/admins` | قائمة المشرفين (من البيئة ومن الأمر) |
| `/admin add <رقم>` / `/admin remove <رقم>` | إضافة/إزالة مشرف (رقم بكود الدولة). لا تستطيع إزالة نفسك ولا مشرف البيئة |
| `/audit [n]` | آخر n عملية إشراف (من فعل ماذا ومتى) |

كل تعديل إعداد أو مصدر أو مشرف يُسجَّل في سجل التدقيق.

## روتين مقترح
1. بعد النشر: `/status` ثم `/sync` وانتظر رسالة النتيجة.
2. أسبوعيًا: `/status` و`/stats` (تحذير stale؟ أخطاء مصادر؟ ملفات مرفوضة؟).
3. عند خلل في ملف معيّن: جرّب إرساله، ثم راجع [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md).
4. احتفظ بنسخة خاصة من متغيرات البيئة ([`MIGRATION.md`](MIGRATION.md)).
