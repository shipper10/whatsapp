# الوضعان: الخفيف والكامل

يعمل البوت بوضعين يُحدَّدان بمتغير واحد: `WHATSAPP_PROVIDER`. باقي المنطق (التصفح، التصنيف، الإرسال،
الأوامر، الإعدادات) واحد في الوضعين؛ الفرق فقط في **طريقة الاتصال بواتساب** وأين يُشغَّل.

## 1. الوضع الخفيف: `WHATSAPP_PROVIDER=baileys`
- مكتبة Baileys تعمل **داخل عملية البوت نفسها**: لا Docker ولا حاوية منفصلة.
- **دخول واتساب (الجلسة) يُحفظ في PostgreSQL** (جدول `wa_auth_state`). لذلك لا يهم أن قرص الاستضافة يُمسح مع كل نشر.
- تربط الرقم من متصفح: `https://<رابط-الخدمة>/admin/link?token=<ADMIN_HTTP_TOKEN>` (رمز QR أو رمز اقتران بالرقم).
- المطلوب: استضافة تشغّل Node 22 + قاعدة PostgreSQL مجانية (Neon أو Supabase).
- مناسب لـ Render المجانية، وهو ما نشرنا عليه.
- ينفرد بميزات: تعديل رسالة التقدم أثناء العمل، وقياس تقدم الرفع (نسبة وسرعة ووقت متبقٍ)، وإرسال الصوت/الفيديو/الصور كأنواع واتساب الأصلية.

## 2. الوضع الكامل: `WHATSAPP_PROVIDER=openwa`
- بوابة **OpenWA** حاوية مستقلة تتصل بواتساب، والبوت يكلّمها عبر REST وويب هوك موقّع.
- الدخول محفوظ في مجلد `openwa-data` على الخادم (يجب نسخه احتياطيًا).
- المطلوب: خادم يشغّل Docker (`docker compose`)، يعمل دائمًا.
- مناسب لمن يملك VPS أو جهازًا لا ينام، ويريد بوابة مستقلة قابلة للاستبدال.
- محدوديات حاليًا: رسالة التقدم ترسل مرة واحدة ولا تُعدَّل، ولا يوجد قياس للرفع، والإرسال يمر عبر `send-document` الخاص بالبوابة.

## جدول المقارنة
| | خفيف (`baileys`) | كامل (`openwa`) |
|---|---|---|
| عدد الحاويات/العمليات | عملية واحدة | بوت + OpenWA + Postgres (+نسخ احتياطي) |
| Docker | غير لازم | لازم |
| مكان دخول واتساب | PostgreSQL | مجلد OpenWA |
| ربط الرقم | صفحة ويب `/admin/link` | واجهة OpenWA أو أوامر curl |
| ينام على الاستضافة المجانية؟ | نعم (يحتاج keep-alive) | لا، إن كان الخادم دائم التشغيل |
| تعديل رسالة التقدم | نعم | لا |
| تقدم الرفع (نسبة/سرعة/وقت) | نعم | لا |
| إرسال صوت/فيديو/صور كأنواعها | نعم | عبر المستند فقط |
| تقسيم الصوت الكبير | نعم | نعم |
| الألبومات والطابور والإعدادات | نعم | نعم |
| النقل لخادم آخر | غيّر المتغيرات فقط (نفس قاعدة البيانات) | انسخ المجلدين وقاعدة البيانات |
| مخاطر الحظر | موجودة (غير رسمي) | موجودة (غير رسمي) |

## كيف أختار؟
- **ليس لديك خادم ولا بطاقة بنكية** → الوضع الخفيف على Render (دليل: [`DEPLOY_LITE.md`](DEPLOY_LITE.md)).
- **لديك VPS دائم التشغيل وتفضّل بوابة منفصلة** → الوضع الكامل ([`DEPLOY_FULL.md`](DEPLOY_FULL.md)).
- يمكن الانتقال من وضع لآخر: الربط بواتساب يُعاد (مسح QR) لأن مكان الدخول يختلف، أما المكتبة والإعدادات في PostgreSQL فتبقى.
