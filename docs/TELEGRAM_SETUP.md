# ربط تيليجرام

يقرأ البوت القناة بحساب تيليجرام حقيقي (MTProto عبر مكتبة `teleproto`)، فيحتاج:
1. مفتاحين من تيليجرام: `api_id` و`api_hash`.
2. جلسة دخول (`TELEGRAM_SESSION_STRING`) لحساب عضو في القناة.

استعمل **حسابًا مخصصًا** للبوت إن أمكن، ولا تشارك الجلسة ولا ترفعها إلى git أبدًا: من يملكها يملك الحساب.

## 1. الحصول على api_id و api_hash (مجانًا)
1. افتح <https://my.telegram.org> وسجّل الدخول برقم الحساب.
2. *API development tools* ← أنشئ تطبيقًا (أي اسم) ← انسخ `App api_id` و`App api_hash`.

## 2. إنشاء جلسة الدخول (مرة واحدة، على أي جهاز عليه Node 22)
```
npm install
TELEGRAM_API_ID=<id> TELEGRAM_API_HASH=<hash> npm run telegram:login
```
أدخل رقم الهاتف (+249…) ثم الرمز الواصل من تيليجرام ثم كلمة مرور التحقق بخطوتين إن وُجدت.
في النهاية يطبع `TELEGRAM_SESSION_STRING=...`. انسخ القيمة إلى متغيرات البيئة في الاستضافة.

## 3. القناة
- `TELEGRAM_CHANNEL` اسم القناة العام (مثل `BahriMed`) أو معرّفها الرقمي.
- يجب أن يكون الحساب عضوًا في القناة (للقنوات العامة يكفي الاشتراك).

## كيف تعمل المزامنة؟
- تقرأ البيانات الوصفية (النص، الاسم، الحجم، النوع، رابط الرسالة، معرّف الألبوم) ولا تنزّل الملفات إلا عند الطلب.
- تمشي بنوافذ من أرقام الرسائل (100 في كل طلب) ومؤشرها يتقدم مع النافذة نفسها، فالرسائل المحذوفة أو الخدمية لا توقفها ولا تنهيها مبكرًا.
- تعيد قراءة **كل رسائل الفهارس** في كل دورة، فتظهر تعديلاتها على الفهارس القديمة، وتعيد قراءة نافذة خلفية من الرسائل الأخيرة (`sync.telegram.rescanWindow`) لالتقاط تعديلات الأوصاف.
- بعد التحديث الذي أضاف دعم الألبومات تقرأ الرسائل المخزنة مرة واحدة لتتعرف على الألبومات.
- متابعة التقدم: `/status` (عدد الرسائل المقروءة)، ويمكن تشغيلها فورًا بـ `/sync telegram`.

## مشاكل شائعة
- «Telegram session is not authorized»: أعد `npm run telegram:login` وحدّث `TELEGRAM_SESSION_STRING` ثم أعد التشغيل.
- لا تظهر الرسائل الجديدة: تحقق من `/status` (آخر مزامنة، تحذير stale) ومن أن الحساب عضو في القناة.
